

\# Smart Guide for Kumbh Mela 2027 — Backend



\## About the Project

This repository contains the Django backend for the Smart Guide for Kumbh Mela 2027 project.



\## Technologies Used

\- Python

\- Django

\- Django REST Framework, if used

\- Database: specify the database used by the project



\## Features

\- Backend API endpoints

\- OTP-related functionality

\- Booking management

\- Backend services for the frontend



\## Setup Instructions

1\. Install Python.

2\. Clone this repository.

3\. Create and activate a Python virtual environment.

4\. Install the required packages from `requirements.txt`, if provided.

5\. Configure environment variables and database settings.

6\. Run database migrations.

7\. Start the development server using `python manage.py runserver`.



\## Security

Do not commit secret keys, passwords, API credentials, or production environment files.
